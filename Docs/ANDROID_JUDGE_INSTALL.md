# ODYSSEY Android Judge Demo

Install `ODYSSEY-Judge-Android-v1.apk` on a 64-bit Android phone with Vulkan support (Android 9 or later). Allow installation from your file manager when Android asks, then open **ODYSSEY Judge**. This is a sideloaded Development demo, not a Play Store release.

After the logo, tap **Solar Transit** to choose Earth, Moon or Mars and **Launch**. **Camera** changes the view. At Earth, **Descend** opens Earth Command. **Begin Mission** opens the station directly.

In the station, use the left movement pad, drag the right side to look, and use **Use / Next / Close** for equipment. **Orbit** returns to Solar Transit. Android Back returns to the menu/orbit where available.

The judge configuration uses **offline exploration**. Station doors and existing local presentations remain available; live incident decisions, campaign saving and backend outcomes require a connected session and are unavailable here. No cloud GPU is required.

The build provider must supply the APK checksum and actual device-test results with the file. Phone compatibility, performance and gameplay remain unverified until tested on a physical device.
