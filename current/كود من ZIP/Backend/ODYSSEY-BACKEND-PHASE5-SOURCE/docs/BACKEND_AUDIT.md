### Defects found and fixed in this pass

| Defect | Impact | Fix |
|---|---|---|
| `app.__version__` missing | **API could not start** (ImportError in `app.main`) | Defined in `app/__init__.py` |
| WebSocket ping matched one exact string | Valid JSON pings with different spacing were ignored | Parse JSON (`is_ping`) |
| WebSocket accepted any ≤ 36-char session id | Weak input validation | Pattern check, close 1008 |
| Rover charger re-charged the rover in the same tick a rover→habitat transfer drained it | Physically wrong two-way energy flow with conversion losses | Charger idle in any tick the rover fed the bus |
| Alembic migration (autogenerated on PostgreSQL) used `now()` defaults | **Migrated SQLite databases failed on first insert**, breaking the documented zero-infrastructure path | `sa.func.now()` (dialect-aware); now tested on both engines |
| Ledger "PostgreSQL trigger" promised in model docs did not exist | Ledger immutability enforced only by the ORM | Triggers for PostgreSQL (with an explicit retention override) and SQLite, in models and migration |
| Redundant indexes (snapshot order, ledger/profile/DNA `timeline_id`) | Write overhead | Removed; unique constraints already cover them |
| `/missions/{id}/metrics` built an engine per request in the route from file data | Bypassed the pinned-scenario engine registry; route reached into the domain | Moved to `MissionService.metric_catalog` |
| `advance` skipped the permission policy | Role policies could not restrict advancing time | `participant_id` + `_authorize(ADVANCE)` |
| `app/telemetry` was an empty package | No aggregate run statistics | `RuntimeStats` + `GET /ops/stats` (non-production) |
| 12 strict-mypy errors, 51 lint findings, unformatted code | Quality gates failing | All resolved; ruff format applied |

Simulation behaviour was verified unchanged by the refactors. State, event, Black Box and
Future Lens hashes are identical before and after, and across processes with different
`PYTHONHASHSEED`s.
